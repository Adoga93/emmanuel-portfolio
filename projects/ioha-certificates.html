Case Study 02 • Production SaaS (165 Certificates Issued)

IOHA Certificates Platform

A full-stack certificate generation, management, and QR-verification web application deployed on Vercel—already used in production to issue 165 QR-verified certificates across 5 international webinars.

The Problem

Manually generating, signing, and verifying attendance certificates for dozens of international webinar attendees is slow and error-prone.

Production Impact

165 live certificates issued across 5 webinars (62, 60, 33, 6, and 4 attendees per cohort), each with a unique ID and scannable QR verification code.

Frontend & PDF Engine

Next.js 16, React 19, Tailwind CSS, pdf-lib + @pdf-lib/fontkit for custom typography, qrcode for verification, and jszip for bulk downloads.

Database & Deployment

Prisma ORM + Aiven PostgreSQL cloud database, bulk CSV parsing via papaparse, and Vercel deployment with strict TypeScript & ESLint CI checks.

How I use this to teach beginners

This is the exact blueprint I teach for Database + Backend + Frontend: a CSV goes in, Prisma stores each record in PostgreSQL, and the browser renders a verifiable PDF on demand.
