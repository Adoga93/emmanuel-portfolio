Case Study 01 • Automation & Live Class Portal

Automated Class & Meeting Recorder (quick-raman)

Built and pushed live so an online instructor can automatically record, organize, and archive every live class without paying a dime in recurring SaaS recording fees.

The Problem

Commercial meeting-recorder bots charge steep monthly subscriptions per seat. The owner needed a reliable way to capture and revisit every live class at zero recurring cost.

The Outcome

A live, automated bot + searchable web portal running end-to-end—saving the owner 100% of recurring SaaS recording fees.

Frontend & Portal

Next.js 16, React 19, Tailwind CSS, Lucide icons, and Google APIs integration for browsing and managing recorded sessions.

Bot, Backend & Deployment

Playwright browser automation (`meeting-bot`), Python indexing/search scripts, and Cloudflare Tunnels (`cloudflared`) for secure live hosting.

What this proves for AI Foundations & Vibe Coding Students

When students learn how APIs, browser automation, frontend portals, and tunnels fit together, they stop seeing AI as just a chatbox—and start building tools that replace expensive subscriptions for real clients.
